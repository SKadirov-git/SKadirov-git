## About

I'm a programmer from Tajikistan, building toward a career in AI engineering. I'm drawn to the full range of software: low-level work in C and C++, interactive web interfaces, and the systems behind intelligent applications. I like understanding how things work under the hood, and I learn best by building. I break a problem into small pieces, write something that runs, then refine it.

I'm also interested in cybersecurity and game development, where logic, creativity, and performance meet. I'm continuously improving my skills, exploring new technologies, and working on practical projects that turn ideas into useful software.
